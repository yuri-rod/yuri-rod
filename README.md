## Selected projects

My public work explores persistent state, predictable failure handling, and practical developer tooling.

- **[Subzero](https://github.com/yuri-rod/subzero)** — Python subtitle-processing toolkit and Jellyfin worker with a persistent SQLite queue, bounded retries, restart recovery, and authenticated operator controls.
- **[Agent Safepoint](https://github.com/yuri-rod/agent-safepoint)** — Rust CLI for workspace checkpoints and file recovery, including preexisting uncommitted work, without creating Git commits. Uses content-addressed storage.
- **[Backchannel](https://github.com/yuri-rod/backchannel)** — Python service that mirrors local coding-agent sessions to a mobile page and accepts messages or files through a token-protected inbox. Built with the standard library.
- **[Railway for macOS](https://github.com/yuri-rod/railway-macos)** — Independent native SwiftUI client with scoped OAuth, Keychain credential storage, and deployment views. **Source-only developer beta.**
